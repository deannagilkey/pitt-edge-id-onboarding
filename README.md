# Pitt EDGE Instructional Designer Onboarding Course

A self-contained website: `index.html` plus an `assets/` folder. Open `index.html` directly in a browser to preview before publishing.

## Getting a shareable link (pick one)

**GitHub Pages** (recommended, to match your other two sites)
1. Create a new public repo on GitHub, e.g. `pitt-edge-id-onboarding`.
2. Upload `index.html` and the `assets/` folder (same level, not nested).
3. Settings → Pages → Source: Deploy from a branch → Branch: main, folder: / (root) → Save.
4. Your link will be `https://yourusername.github.io/pitt-edge-id-onboarding/`.

**Netlify Drop**
1. Go to https://app.netlify.com/drop
2. Drag this whole folder onto the page.
3. You'll get a live URL in seconds.

## Linking it up

The main portfolio (`instructional-design-portfolio`) already links to this site from its "Pitt EDGE Instructional Designer Onboarding Course" section. This site links back to the main portfolio in the line just under the hero ("← Back to full portfolio").

If you use a repo name other than `pitt-edge-id-onboarding`, update:
1. The link URL in the main portfolio's `index.html` (search for `id-onboarding` section, the `<a class="link-tile" href=...>`).
2. Nothing else needs to change on this site itself.
