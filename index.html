Course Overview

A Performance-Support Course for New Pitt EDGE Designers

This Canvas course onboards new Pitt EDGE instructional designers during their first 30–90 days, then stays in place afterward as an ongoing performance-support resource — the same page a designer returns to six months in when they forget which SharePoint site holds the project template.

This course is still in development. Modules 0 through 4 are built out below in full, along with a new Pitt Professional module added after the original map was set. The remaining modules are structured in Canvas already and are being built out next; the course closes with a knowledge check and a certificate.

Full Scope

The Full Course Map

Modules 0 through 10, shown here as they exist in Canvas today. This is the real module list, not a planning document — every title below is a page a new designer will actually open.

Module 0

Onboarding & Operations

Everything a new designer needs before touching a course build: who's who, how the team communicates, what's mandatory, and what technology they'll have access to. The module front-loads logistics so later modules can stay focused on actual design and development work.

Module 1

Pitt EDGE Programs & Partnerships

Grounds a new designer in the actual academic landscape they'll support — real schools, real programs, real staffing models — before any process training begins. A designer who knows what OneID, Pillar, and Legacy programs actually are can prioritize their own work correctly from day one.

Module 2

Course Development Lifecycle

The four-phase methodology every course built at Pitt EDGE follows: Design → Develop → Deploy/Term Prep → Launch. Each phase is anchored to a named checkpoint and a single deliverable that defines what 'done' actually means, so handoffs between faculty, designers, and QA don't depend on anyone's memory.

Module 3

Starting & Managing a Project

Instructional designers at Pitt EDGE serve as project managers for their own course developments — coordinating faculty, deliverables, timelines, reviews, and handoffs from kickoff through launch. This module covers what to review when a new assignment lands, the systems used to track it, and how to close it out cleanly when it's done.

Module 4

Developing Courses in Canvas

The operational core of the course: how a designer actually builds in Canvas at Pitt EDGE. Covers the three platforms in play, the three Canvas environments, shell naming and promotion, the master template, and the two tools (DesignPLUS and UDOIT) that shape and check the final build.

New Module · Pitt Professional

Pitt Professional

Added after the original module map was set: a dedicated module on Pitt Professional, the platform behind Pitt EDGE's non-credit, professional development, and continuing education offerings. Final module numbering is still being finalized as this gets built out.
